Claude Code 接入第三方 API：完整配置与踩坑清单

Claude Code 用的是 Anthropic 协议，不是 OpenAI 协议——这是 90% 的人配不通的原因。下面是最小可用配置，以及 401 / 404 / 429 分别代表什么。

一、最小可用配置

export ANTHROPIC_BASE_URL="https://api.cocoapi.top"   # 网关根地址
export ANTHROPIC_AUTH_TOKEN="sk-你的密钥"
export ANTHROPIC_API_KEY=""                           # 必须留空

claude

三行里最容易错的是第三行。只要 ANTHROPIC_API_KEY 有值，Claude Code 就可能走官方鉴权通道，把你的第三方密钥当官方 key 发出去，结果是 401。

二、为什么 ANTHROPIC_BASE_URL 不能带 /v1

Claude Code 会自己在根地址后拼 /v1/messages。你如果填了 https://xxx/v1，最终请求会变成 https://xxx/v1/v1/messages → 404。

协议Base URL 示例最终请求
Anthropic（Claude Code）https://api.cocoapi.top/v1/messages
OpenAI 兼容（Cursor 等）https://api.cocoapi.top/v1/v1/chat/completions

三、报错对照表

现象最可能的原因怎么查
401 Invalid token密钥无效/过期，或 ANTHROPIC_API_KEY 没清空用 curl /v1/models 单独验证 key
404 not found路径重复 /v1，或把网页地址当接口看最终请求 URL
402 / 余额相关钱包余额不足，或密钥额度/分组限制控制台看余额 + 密钥分组
429并发或频率超限（免费档最常见）降并发、加间隔、换轻量模型
返回 HTML 而不是 JSON请求打到了网页/错误页核对路径与 Content-Type

四、怎么确认“我买的是不是真 Opus”

中转站最大的风险不是跑路，是偷偷降级。三个可执行的自检：

  • 同一提示词分别用 Opus 与 Sonnet 跑，观察输出风格与耗时差异是否与分组倍率一致；
  • 看响应里的 model 字段与计费明细中的模型名是否与你请求的一致；
  • 用第三方检测工具或自建盲测脚本，长期跟踪可用率。

以 COCO API 为例，其分组倍率在模型广场公开（Claude 各池倍率不同），你可以据此反推实际计费是否符合预期。是否划算请自己核价，本文不做推荐承诺。

五、要不要用免费额度跑 Claude Code

可以，但要认清定位：免费档适合跑通流程、试模型、写小脚本；不适合长时间 Agent 任务（一次任务几十万 token 很常见，免费额度撑不住）。建议先在付费分组小额测试，再决定主力渠道。
