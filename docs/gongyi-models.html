公益模型（0 倍率分组）是什么，能白嫖到什么程度

「公益模型」是 AI API 中转站里的一种分组策略：把某些模型的分组倍率设为 0，调用不扣额度。它真实存在，但有三条硬限制，不理解就会白折腾。

一、机制：倍率 0 意味着什么

中转站的计费公式大致是：消耗 = 模型单价 × 分组倍率 × token 数。倍率为 0 时，前两项乘积为 0，所以只要你的密钥绑在该分组、余额不为负，调用就不扣钱。

你看到的含义
分组倍率 0该分组内模型不扣费
分组倍率 0.1 / 0.3按官方价 1 折 / 3 折计费
每日签到每天领固定额度，属于另一种免费来源

二、三条硬限制

  • 清单会变。公益组是拉新和口碑手段，今天有 Opus 不代表下周还有。判断依据只有模型广场的实时展示。
  • 密钥要绑分组。在模型广场切换筛选不会改变已创建密钥的分组，必须在密钥设置里指定。
  • 并发不会高。公益组通常限制并发或排队，长链路 Agent 任务容易被中断。

三、怎么判断一个站点的“公益”靠不靠谱

  1. 额度与分组能否在不登录的公开页面查到（模型广场、状态接口）；
  2. 计费是否逐笔可查（有调用明细 = 敢给你对账）；
  3. 是否要求你交主账号、Cookie、长期令牌——要求这些的直接放弃；
  4. 有没有“用完即停”开关，避免免费额度用完后自动扣余额。

以 COCO API 为例：公益组的存在写在其站内公告里（2026-10-27 上线），当前启用 122 个模型，每日签到开关可通过 /api/status 的 checkin_enabled 字段核对，模型广场与价格页均无需登录即可查看。这些都可以自己验证，不必信本文。

五、常见误区

误区实际
“公益模型 = 无限免费随便用”有并发与模型范围限制，随时可能调整
“网页聊天免费，所以 API 也免费”两个不同产品，计费体系完全不同
“注册送 X 元”长期有效多数是限时活动，过期即无
“公益组能跑生产”不能。生产必须准备付费额度与备用渠道
