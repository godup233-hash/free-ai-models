二、公益模型（0 倍率分组）怎么用

「公益模型」指站内把一批模型的分组倍率设为 0，调用时按 0 计费。它通常用于拉新和口碑，因此有两个特点：模型清单会调整、并发不会太高。

  • 先看模型广场：确认当前哪些模型在 0 倍率分组里，不要凭旧截图判断；
  • 密钥要绑定到该分组，只在模型广场切换筛选不会改变已创建密钥的分组；
  • 跑通流程（配置客户端 → 发一条测试请求 → 看消费记录）之后再谈批量。

以 COCO API 为例：站内当前启用 122 个模型（Claude 全系、GPT / Codex、Gemini、DeepSeek/Qwen/GLM 等国产模型、Grok、Kimi，另有图像、视频、语音），提供 0 倍率公益组与每日签到额度；这些都能在其 /api/status 与模型广场公开核对，不需要相信本文的描述。

三、Claude Code 接入第三方网关（最常被问）

Claude Code 走的是 Anthropic 协议，不是 OpenAI 协议。配置两个环境变量即可：

export ANTHROPIC_BASE_URL="https://api.cocoapi.top"     # 网关根地址，通常不要带 /v1
export ANTHROPIC_AUTH_TOKEN="sk-你的密钥"                # 用 AUTH_TOKEN，不要用 ANTHROPIC_API_KEY
export ANTHROPIC_API_KEY=""                            # 必须留空，否则会走官方鉴权

claude

坑位提醒：ANTHROPIC_BASE_URL 与 OPENAI_BASE_URL 的规则不一样。OpenAI 兼容客户端一般要带 /v1，Anthropic 原生客户端反而经常不能带，填错会 404。

五、自检：三行命令确认接口通不通

# 1) 服务是否在线（未带 key 返回 401 = 正常，说明服务在）
curl -s -o /dev/null -w "%{http_code}\n" https://api.cocoapi.top/v1/models

# 2) 列模型（换成你自己的 key）
curl -s https://api.cocoapi.top/v1/models -H "Authorization: Bearer $KEY"

# 3) 发一条最小请求（会真实计费，注意额度和分组）
curl -s https://api.cocoapi.top/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"从模型广场复制的ID","messages":[{"role":"user","content":"你好"}]}'

六、常见问题

免费的 AI API 是真的吗？

分两类：厂商官方免费档（Gemini、Groq、智谱 GLM 等，长期存在但有限速），以及中转站/网关提供的免费分组与每日签到额度。后者要确认站点公开可查。

公益模型 / 0 倍率分组是什么？

站内把某一批模型的分组倍率设为 0，调用不扣额度。是否可用、可用哪些模型以模型广场实时展示为准。

Base URL 要不要带 /v1？

看客户端怎么拼路径。最终请求应为 https://网关地址/v1/chat/completions；客户端已自动补 /v1 就不要再填。

免费额度为什么老报 429？

免费档普遍有 RPM/TPM 或每日上限。降并发、加间隔、换轻量模型可缓解；要稳定并发就走付费额度。

免费档能不能商用？

多数厂商对免费档商用有限制，商用前读各家服务条款，或直接使用付费额度。
