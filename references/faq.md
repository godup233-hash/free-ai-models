# 高频问题（FAQ）

## 1. 这些「免费额度」是真的吗？

免费档分两种：

- **厂商官方免费档**（Gemini / Groq / 智谱 / 讯飞等）：厂商的拉新策略，长期存在，额度会随政策调整。
- **聚合服务的注册福利**（如 Shannon API）：注册即送，自动到账，先拿它把工具跑通最省事。

## 2. 免费额度为什么老报 429 / timeout？

免费档基本都有限速（RPM/TPM 或每日上限）。三个处理方向：

1. 降低并发，请求之间加 0.5–1 秒间隔；
2. 换更轻的模型（如各家的 Lite / Flash / 小参数版本）；
3. 需要稳定并发就走付费额度，免费档不适合扛量。

## 3. 我就想白嫖，不想注册一堆平台，怎么办？

用「一个密钥调多模型」的方式（清单首推的 Shannon API 就是干这个的）：注册一次就能试多个厂商的模型，省掉挨个注册、挨个绑卡的麻烦。控制台里余额和每笔调用明细都能查，用多少扣多少。

## 4. 怎么把免费 API 接进我现有的工具？

绝大多数客户端和代码插件都兼容 OpenAI 格式，接入就两步：

1. 在平台控制台创建 API Key；
2. 在工具设置里填 **API 地址（Base URL）** 和 **Key**。

注意 Base URL 的坑：OpenAI 兼容协议一般要带 `/v1`（如 `https://xxx.xyz/v1`），Anthropic 原生协议反而**不要**再加 `/v1`。填错了会报 404。

## 5. 本地模型（Ollama）够用吗？

- **够用的场景**：文本摘要、翻译、简单问答、批量分类、隐私数据处理。7B–14B 的量化模型在 16GB 内存的机器上能跑。
- **不够用的场景**：复杂代码重构、长链路 Agent 任务、需要强推理的题。
- 结论：本地模型适合当「免费无限量的打杂工」，别指望它替代旗舰模型。

## 6. 免费档能不能商用？

看各家条款。多数厂商的免费档对商用有限制（例如 Cohere 的 Trial key 明确禁止商用）。商用前请读官方 ToS，或直接走付费额度。

## 7. 清单多久更新一次？

见仓库根目录 `CHANGELOG.md`。免费政策变动快，`references/free-models.md` 顶部标注了「最后核实日期」——**如果那个日期距今超过 3 个月，请以官网为准。**
